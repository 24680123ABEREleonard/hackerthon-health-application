ABOUT THIS DEMO

A thoughtful path to review.

A starting point for making diagnostic workflows more accessible — not a diagnostic system.

Prototype status: browser demo only.

This page stores case records in browser local storage. The Android app version includes a local SQLite database and an optional AI helper for software-help topics only; no clinical AI or image analysis is connected.

01

Capture an imaging case

Add a fictional or non-identifying case ID, select an image type and priority, and optionally choose an image to preview. The image is read in your browser and is not uploaded or stored.

02

Keep the review queue organized

Search cases, filter by review status, and open a case to record that a qualified clinician has reviewed it. Case records are saved in this browser using local storage.

03

Plan for offline-first care

The interface is designed to be usable without a stable connection. This demonstration has no sync service, encryption guarantees, access controls, or production-grade patient-data protections.

Not for real patient data or clinical decisions.Use a validated, regulated clinical system for patient care. A qualified medical professional must make all diagnostic and treatment decisions.

Designed with care

Health software needs more than a helpful interface. It needs validated clinical evidence, privacy safeguards, accessibility, reliable infrastructure, and accountable human oversight.

CURRENT DEMO SCOPE
  • Local case management
  • Client-side image preview
  • Search and review queue
  • No clinical model inference
  • No data transmission from browser demo

The Android app separately offers optional, locally configured AI for software help only.
